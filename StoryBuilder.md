## Project Description:
The Collaborative Story Writing Platform is a fun and interactive web app that allows multiple users to collaboratively create stories. Users can choose a story title and write their individual versions without knowing what others are contributing. The platform uses AI to merge the individual contributions into a unique and cohesive story, which is then published for everyone to enjoy.

### Features:
- Real-time collaboration using Next.js and Supabase.
- Intuitive UI designed with Tailwind CSS and enhanced animations via Framer Motion.
- Seamless integration with Lens Protocol using ConnectKit.
- AI-powered story merging for a unique and personalized outcome.

## Tech Stack:
- **Frontend:** Next.js, Tailwind CSS
- **Backend:** Supabase
- **Web3 Integration:** Lens Protocol via ConnectKit
- **Animations:** Framer Motion
- **Hosting:** Vercel
