# Project Name
Aura - Community-Driven Smart Contract Reviews

## Team Members
Watcher - [@watchereth]

## Project Description
Aura serves as a crucial tool in the blockchain ecosystem by providing user-generated reviews for smart contracts, helping users make informed decisions about contract safety and functionality. The platform leverages Lens Network for gasless reviews and offers:

- Multi-chain support across major EVM networks
- Gasless transactions powered by Lens Network
- Fully on-chain reviews with metadata storage
- Easy integration through GraphQL API
- Extensible architecture for custom implementations

Key problems solved:
- Trust Gap: Bridging the gap between users and smart contracts through community reviews
- Information Asymmetry: Providing practical insights beyond the code
- Community Wisdom: Aggregating user reviews for better decision-making
- Social Discovery: Enabling community formation around emerging contracts
