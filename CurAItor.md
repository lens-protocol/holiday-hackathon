## Project Description

The current system on Lens requires consumers to search across an overwhelming amount of digital content. This makes content discovery complex and creates friction through multiple blockchain transactions and complex token interactions.

CurAItor is an AI-powered marketplace built on Lens Protocol that enables content distribution through intelligent curation. 

The system creates a three-sided marketplace connecting creators, AI curators, and consumers through a unique content management approach.

CurAItor separates uploaded content into two components: the original asset and its AI-generated mathematical representation (embeddings). Original content and embedding are stored separately on a dual storage system to preserve creators privacy and control over their creations.

This separation allows AI agents to automatically curate content by analyzing these embeddings without accessing the actual assets, preserving creator privacy and control.

This is possible since AI agents continuously monitor smart contracts for new content, analyze similarity patterns, and make automated purchasing decisions based on predefined criteria. 

This allows Lens users to subscribe to these AI-curated collections, eliminating the need for individual purchases while ensuring they receive relevant, quality content.

### Smart Content Storage Architecture
The platform implements a sophisticated dual-storage system that manages content in two distinct layers. When a creator uploads content (currently supporting images in MVP), the system automatically:

- Stores the original asset in a dedicated folder within Lens Network nodes
- Generates mathematical embeddings representing the content's semantic features
- Links both components through NFT metadata on the blockchain
- Enables future encryption capabilities where only NFT holders can decrypt content

### AI-Powered Curation Engine
The autonomous curation system operates through a multi-step process:

- Continuously monitors the Lens Protocol contract factory for new publications
- Retrieves and analyzes content embeddings from the Lens Network
- Performs vector similarity analysis against existing collections
- Evaluates content based on configurable criteria (pricing, quality metrics, relevance)
- Executes automated purchasing decisions through smart contracts
- Provides structured feedback to creators explaining curation decisions

### Privacy-Preserving Architecture
The system's privacy features are built around:

- Separation of content representation from raw assets
- Embeddings-based similarity matching that never exposes original content
- Smart contract integration that manages access control
- Future-ready design for implementing asset encryption
- NFT-based access control mechanisms for content decryption
